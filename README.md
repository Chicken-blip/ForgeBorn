# Forgeborn
A turn-based construct-raising game. You raise one construct through a fixed
calendar of turns — training its stats, fitting parts, learning skills from a
combination web — and test it in duels against a designed rival ladder. Lose a
critical duel and the run ends. Win the final duel and the run is complete.
Either way, a new run begins with a fresh construct. Across runs you keep
unlocks, not power.

## Status:
In-design, not playable. Core to be built first before UI implementation
